# utterance_attest (Dart)

Sign and verify short-lived, single-utterance speaker attestations for
voice agents. See the [repository README](../README.md) for the API examples and [`../SPEC.md`](../SPEC.md) for the wire format.

## Install

Use a local path dependency. From `vouch/vouch_flutter/pubspec.yaml`, the path to this package would be:

```yaml
dependencies:
  utterance_attest:
    path: ../../oss/utterance-attest/dart
```

Adjust the path for another application. The package is not installed from pub.dev by this example.
