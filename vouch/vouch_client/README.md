# Vouch Dart client

Serverpod generates this package from the backend endpoints and models. The Flutter app uses it for typed requests and responses. Change server endpoint code or `.spy.yaml` definitions, then regenerate through the workspace's Serverpod workflow; generated files will be overwritten.

Follow the [workspace setup guide](../../README.md#fastest-way-to-try-it-no-hub-no-mic) to install dependencies and start the app. See [endpoint calls](doc/endpoint.md) for a request example.
